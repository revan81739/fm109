# Windwhisper Ridge
windwhisper ridge is an evp radio style game built with python where the player is searching for clues to the code for a lockbox. its loosely horror-based, though i doubt you're going to get very scared(no jumpscares i promise)

![](https://github.com/user-attachments/assets/e5221bdc-5c29-4033-8872-4a1f85640d1e)

## Gameplay
Release build can be found [here](https://github.com/revan81739/windwhisper_ridge/releases/tag/v1)

Tune through the radio to find radio stations-if you find anything interesting, listen to the whole thing and log the transmission in the storm lookout logs

![](https://github.com/user-attachments/assets/68b8447a-ccfb-4119-98d3-42ab7e40146d)

Look through your logs to find the code to the lockbox

![](https://github.com/user-attachments/assets/6c5b6625-77c9-4075-9710-84daae439017)

and thats really it. no rocket science here
one line of audio was recorded by me-everything else is public domain(shoutout the goat umm kulthum for the banger music-shes long gone but still shoutout)

(the game was built with pygame and tkinter, and all images were drawn in libresprite by yours truly)
